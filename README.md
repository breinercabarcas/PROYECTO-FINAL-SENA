# 📊 Dashboard de Ventas – Power BI

## 📌 Descripción

Proyecto de análisis y visualización de datos desarrollado en **Power BI**, orientado al análisis del comportamiento de las ventas desde diferentes perspectivas.

El Dashboard permite explorar información relacionada con **clientes, productos, marcas, países y continentes**, facilitando la interpretación de los datos y apoyando la toma de decisiones.

## 🎯 Objetivo

Transformar un conjunto de datos de ventas en información visual, organizada e interactiva mediante un Dashboard desarrollado en Power BI.

## 🛠️ Herramientas utilizadas

* **Power BI** – Modelado, medidas DAX y visualización.
* **Microsoft Excel** – Fuente de datos.
* **DAX** – Creación de medidas e indicadores.
* **Power Query** – Preparación y transformación de datos.

## 📈 Análisis realizado

El Dashboard permite analizar:

* Ventas totales.
* Costos y utilidad.
* Clientes.
* Productos y marcas.
* Unidades vendidas.
* Ventas por país.
* Ventas por continente.
* Top 10 de clientes.
* Distribución geográfica de las ventas.

## 📊 Principales visualizaciones

El proyecto incluye diferentes elementos interactivos, entre ellos:

* KPI de Total Clientes.
* Ranking Top 10 de clientes.
* Mapa de distribución global de ventas.
* Ventas por continente.
* Ventas totales por país.
* Filtros interactivos por cliente.

## 📐 Medidas DAX

Entre las principales medidas utilizadas se encuentran:

* Costos Totales
* Margen de Ganancia
* Total Clientes
* Total Marcas
* Total Productos
* Unidades Vendidas
* Utilidad Promedio
* Utilidad Total
* Ventas Totales
